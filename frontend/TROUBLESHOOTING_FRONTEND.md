# Решение проблем с Frontend (Bus error)

Если при запуске `npm run dev` вы получаете ошибку `Bus error (core dumped)`, это обычно связано с повреждением кэша или проблемными зависимостями в `node_modules`.

## Быстрое решение (Clean Install)

Выполните следующие команды в папке `frontend`:

```bash
# 1. Удалите папку зависимостей и кэш
rm -rf node_modules .vite

# 2. Очистите кэш npm
npm cache clean --force

# 3. Установите зависимости заново
npm install

# 4. Запустите проект
npm run dev
```

## Если проблема сохраняется

### 1. Проверьте версию Node.js
Рекомендуется использовать LTS версию (18 или 20). Проверьте вашу версию:
```bash
node -v
```

### 2. Проблема с файловой системой (HDD/SSD)
Ошибка `Bus error` иногда возникает, если проект находится на внешнем диске или сетевом ресурсе с ограничениями прав доступа. Попробуйте перенести папку проекта на основной системный диск.

### 3. Ограничения ресурсов
Если у вас запущено много тяжелых процессов (например, LLM), Node.js может не хватать памяти для компиляции. Попробуйте временно остановить бэкенд и запустить фронтенд отдельно.

### 4. Обновление системных пакетов
Как видно на вашем скриншоте, система рекомендует обновить `libsystemd0` и `libudev1`. Выполните:
```bash
sudo apt update
sudo apt install libsystemd0 libudev1
```
