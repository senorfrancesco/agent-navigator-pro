# llm-tools-platform

Агентный интерфейс для анализа документов, RAG-поиска, сравнения юридических материалов и проверки соответствия ТЗ/КП.

Что доступно:
- анализ одного документа;
- сравнение двух документов;
- ответы по содержимому загруженных файлов;
- анализ оборудования и отчёты по соответствию.

Рекомендации:
- для анализа сначала загрузите документы;
- для вопросов по файлам используйте один чат на один набор документов;
- ответы LLM могут ошибаться, критичные выводы проверяйте по исходному документу.
