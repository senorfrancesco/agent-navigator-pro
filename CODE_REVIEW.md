# Ревью кода agent_api.py - Анализ проблемы галлюцинаций

## Обнаруженные проблемы

### 1. **Недостаточные стоп-токены (строка 80)**

**Текущий код:**
```python
"stop": ["Observation:", "Human:", "\n\nHuman:"]
```

**Проблема:** 
- Модель не останавливается после завершения ответа
- Отсутствуют стоп-токены для предотвращения самодиалога
- Модель может продолжать генерировать текст вида "User:", "Понял, спасибо...", "Ответ:" и т.д.

**Решение:**
Добавить более строгие стоп-токены:
```python
"stop": [
    "Observation:", 
    "Human:", 
    "\n\nHuman:",
    "User:",
    "\n\nUser:",
    "Вопрос:",
    "\n\nВопрос:",
    "###",
    "\n\n\n",
    "Понял, спасибо",
    "```plaintext"
]
```

### 2. **Слабый системный промпт (строки 112, 124)**

**Текущий код:**
```python
prompt = f"Ты — ассистент Agent Navigator Pro. Ответь на запрос пользователя: {query}\n\nОтвет:"
```

**Проблема:**
- Промпт не содержит четких инструкций об ограничении ответа
- Нет указания отвечать только на текущий вопрос
- Отсутствует запрет на имитацию диалога

**Решение:**
Улучшить промпт с четкими инструкциями:
```python
prompt = f"""Ты — ассистент Agent Navigator Pro. 

ВАЖНО:
- Ответь ТОЛЬКО на текущий запрос пользователя
- НЕ придумывай дополнительные вопросы или ответы
- НЕ имитируй диалог с пользователем
- Закончи ответ сразу после того, как ответишь на вопрос

Запрос пользователя: {query}

Твой ответ:"""
```

### 3. **Отсутствие параметров контроля повторений**

**Текущий код:**
```python
payload = {
    "prompt": prompt,
    "max_tokens": settings.get("maxTokens", 2048),
    "temperature": settings.get("temperature", 0.7),
    "stop": ["Observation:", "Human:", "\n\nHuman:"]
}
```

**Проблема:**
- Нет параметров `frequency_penalty` и `presence_penalty`
- Модель может зацикливаться на повторяющихся фразах
- Отсутствует контроль за разнообразием текста

**Решение:**
Добавить параметры штрафов:
```python
payload = {
    "prompt": prompt,
    "max_tokens": settings.get("maxTokens", 2048),
    "temperature": settings.get("temperature", 0.7),
    "frequency_penalty": settings.get("frequency_penalty", 0.3),
    "presence_penalty": settings.get("presence_penalty", 0.3),
    "repetition_penalty": settings.get("repetition_penalty", 1.1),
    "stop": [...]
}
```

### 4. **Проблема с обработкой коротких запросов (строка 109)**

**Текущий код:**
```python
is_simple = not attachments and len(query.split()) < 10
```

**Проблема:**
- Запрос "Что?" считается простым и обрабатывается без контекста
- Нет проверки на осмысленность запроса
- Модель пытается ответить на неопределенный вопрос

**Решение:**
Добавить проверку на неопределенные запросы:
```python
# Проверка на неопределенные запросы
ambiguous_queries = ["что", "что?", "как", "как?", "почему", "почему?", "зачем", "зачем?"]
if query.strip().lower() in ambiguous_queries:
    yield AgentStep(
        id=str(uuid.uuid4()), 
        type="final_answer", 
        content="Ваш запрос слишком неопределён. Пожалуйста, уточните, что именно вас интересует.", 
        timestamp=time.time()
    )
    return
```

### 5. **Отсутствие постобработки ответа**

**Проблема:**
- Нет фильтрации артефактов вроде "```plaintext"
- Модель может включать в ответ служебную разметку
- Отсутствует обрезка ответа при обнаружении самодиалога

**Решение:**
Добавить постобработку:
```python
def clean_response(text: str) -> str:
    """Очистка ответа от артефактов и самодиалога."""
    # Удаление служебной разметки
    text = re.sub(r'```plaintext.*?```', '', text, flags=re.DOTALL)
    text = re.sub(r'```.*?```', '', text, flags=re.DOTALL)
    
    # Обрезка при обнаружении самодиалога
    stop_patterns = [
        r'\n\n(User:|Human:|Вопрос:|Понял, спасибо)',
        r'\n\nОтвет:',
        r'\n\n###'
    ]
    for pattern in stop_patterns:
        match = re.search(pattern, text)
        if match:
            text = text[:match.start()]
            break
    
    return text.strip()
```
