Пользователь передаёт номер TD (например "TD-3" или просто "3").

Алгоритм:
1. Прочитай `/home/seral/HDD/proj/agent-navigator-pro/TASKS.md`
2. Найди задачу с нужным номером в разделе `## Tech Debt`
3. Изучи описание проблемы и предложенный Fix
4. Прочитай файлы, которые нужно изменить
5. Реализуй fix
6. Запусти релевантные тесты через `cd backend && python -m pytest tests/ -v --tb=short -q`
7. После успешных тестов отметь задачу выполненной в TASKS.md: `[ ]` → `[x]`

Если номер не указан — выведи список всех незакрытых TD-задач из TASKS.md с кратким описанием.
