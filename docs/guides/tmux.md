# Руководство по tmux

Tmux — терминальный мультиплексор. В проекте используется для запуска всех backend-сервисов в одной tmux-сессии `llm-tools-platform`.

---

## Установка конфига

Конфигурация хранится в `config/tmux/` (On My Tmux). Скопировать в систему:

```bash
mkdir -p ~/.config/tmux
cp config/tmux/tmux.conf ~/.config/tmux/tmux.conf
cp config/tmux/tmux.conf.local ~/.config/tmux/tmux.conf.local
```

Или через симлинки (изменения в репо сразу применяются):

```bash
ln -sf "$(pwd)/config/tmux/tmux.conf" ~/.config/tmux/tmux.conf
ln -sf "$(pwd)/config/tmux/tmux.conf.local" ~/.config/tmux/tmux.conf.local
```

После изменения конфига — перезагрузить без перезапуска tmux:

```bash
# внутри tmux-сессии:
<prefix> r
```

Или отредактировать конфиг прямо из tmux:

```bash
<prefix> e   # открывает tmux.conf.local в $EDITOR, после сохранения — автоматически перезагружает
```

## Префиксы

В конфиге настроено **два** префикса:

| Префикс | Клавиши | Описание |
|---------|---------|----------|
| Основной | `Ctrl + B` | Стандартный tmux |
| Вторичный | `Ctrl + A` | GNU Screen совместимый |

Оба работают одновременно. В этом руководстве `<P>` = любой из них.

---

## Запуск и подключение

```bash
# Запуск системы (создаёт сессию llm-tools-platform автоматически)
./scripts/launcher.sh --target native

# Подключиться к существующей сессии
tmux attach -t llm-tools-platform

# Посмотреть все сессии
tmux ls

# Новая сессия вручную
tmux new -s my-session

# Отключиться от сессии (не убивая)
<P> d
```

## Хоткеи

> `<P>` = нажать `Ctrl+B` (или `Ctrl+A`), отпустить, затем нажать следующую клавишу.
> `-r` = клавиша повторяемая (можно держать и нажимать несколько раз подряд).

### Сессии

| Действие | Комбинация |
|----------|-----------|
| Отключиться (detach) | `<P> d` |
| Список сессий | `<P> s` |
| Новая сессия | `<P> C-c` |
| Найти сессию по имени | `<P> C-f` |
| Переключиться на последнюю сессию | `<P> BTab` |
| Переименовать сессию | `<P> $` |

### Окна (вкладки)

| Действие | Комбинация |
|----------|-----------|
| Новое окно | `<P> c` |
| Следующее окно | `<P> C-l` |
| Предыдущее окно | `<P> C-h` |
| Последнее активное окно | `<P> Tab` |
| Перейти к окну по номеру | `<P> 0..9` |
| Список окон | `<P> w` |
| Переименовать окно | `<P> ,` |

### Панели (panes)

| Действие | Комбинация |
|----------|-----------|
| Разделить **горизонтально** (нижняя панель) | `<P> -` |
| Разделить **вертикально** (правая панель) | `<P> \` |
| Перейти влево | `<P> h` (повторяемый) |
| Перейти вниз | `<P> j` (повторяемый) |
| Перейти вверх | `<P> k` (повторяемый) |
| Перейти вправо | `<P> l` (повторяемый) |
| Изменить размер влево | `<P> H` (повторяемый) |
| Изменить размер вниз | `<P> J` (повторяемый) |
| Изменить размер вверх | `<P> K` (повторяемый) |
| Изменить размер вправо | `<P> L` (повторяемый) |
| Развернуть панель на весь экран | `<P> +` |
| Показать номера панелей | `<P> q` |
| Переставить панель вправо | `<P> >` |
| Переставить панель влево | `<P> <` |
| Включить/выключить мышь | `<P> m` |
| Очистить историю панели | `C-l` (без префикса) |

### Копирование текста (vi-режим)

Конфиг использует vi-навигацию в copy-mode. Для workspace-сессии `Codex`, поднятой через [launch_codex_tmux_workspace.sh](/home/seral/HDD/proj/agent-navigator-pro/scripts/launch_codex_tmux_workspace.sh:32), клавиша `y` копирует выделение в буфер `tmux` и сразу пробует системный clipboard в таком порядке: `wl-copy` на `Wayland`, затем `xclip`, затем `xsel`.

| Действие | Комбинация |
|----------|-----------|
| Войти в режим копирования | `<P> Enter` или `<P> [` |
| Начать выделение | `v` |
| Прямоугольное выделение | `C-v` |
| Копировать выделение (и выйти) | `y` → копируется в буфер tmux и в доступный системный clipboard helper |
| Начало строки | `H` |
| Конец строки | `L` |
| Выход из copy-mode | `Escape` или `q` |
| Вставить из буфера tmux | `<P> p` |
| Список буферов вставки | `<P> b` |
| Выбрать буфер для вставки | `<P> P` |

### Прочее

| Действие | Комбинация |
|----------|-----------|
| Перезагрузить конфиг | `<P> r` |
| Редактировать `tmux.conf.local` | `<P> e` |
| Список горячих клавиш | `<P> ?` |
| Командная строка tmux | `<P> :` |

## Настройки конфига (`tmux.conf.local`)

Что задано в `config/tmux/tmux.conf.local`:

| Параметр | Значение | Описание |
|----------|----------|----------|
| Второй префикс (`tmux.conf`) | `Ctrl+A` | GNU Screen стиль |
| `tmux_conf_theme` | `enabled` | Oh My Tmux тема |
| `tmux_conf_24b_colour` | `true` | True color (24-bit) |
| `tmux_conf_theme_status_bg` | `#191724` | Тёмный фон статус-бара (Rosé Pine) |
| `mode-keys` | `vi` | Vi-навигация в copy-mode |
| `set-clipboard` | `on` | Разрешает tmux пробрасывать clipboard наружу |
| Launcher clipboard bind | `y` | Для Codex workspace использует `wl-copy` / `xclip` / `xsel` |
| `tmux_conf_new_pane_retain_current_path` | `true` | Новая панель в той же директории |
| Сепараторы | powerline-символы | Требуют Nerd Font или patched шрифт |

Status-bar слева: `❐ <session-name>`, справа — пуст (очищен в конфиге, индикатор префикса и батарея закомментированы).

## Частые проблемы

**Сессия уже существует при перезапуске:**
```bash
./scripts/stop_all.sh
./scripts/launcher.sh --target native
```

**Нет цветов / битые символы в статус-баре:**
Убедиться что терминал поддерживает true color и Nerd Fonts. В `~/.bashrc`:
```bash
export TERM=xterm-256color
```

**`y` не копирует в системный буфер:**
```bash
sudo apt-get install -y xclip
# для нативного Wayland-варианта вместо XWayland fallback:
sudo apt-get install -y wl-clipboard
```

**Нужно вручную переложить текущий `tmux` buffer в системный clipboard:**
```bash
tmux save-buffer - | xclip -selection clipboard -in
# или, если установлен Wayland helper:
tmux save-buffer - | wl-copy
```

**Конфиг не применяется после правок:**
```bash
# Из tmux
<P> r

# Или полностью убить и перезапустить
tmux kill-server
```
