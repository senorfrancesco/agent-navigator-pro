# `tmux` бинды из кастомной конфигурации

Источник:
- `config/tmux/tmux.conf`
- `config/tmux/tmux.conf.local`

Этот файл фиксирует активные бинды из кастомного конфига проекта. Стандартные бинды `tmux` в целом остаются доступными, кроме явно переопределённых или снятых.

## Префиксы

- `Ctrl+B` — стандартный префикс `tmux`
- `Ctrl+A` — дополнительный префикс через `prefix2`

## Без префикса

- `Ctrl+L` — очистить экран и историю текущей панели

## Сессии

- `<prefix> Ctrl+C` — создать новую сессию
- `<prefix> Ctrl+F` — найти и переключиться на сессию
- `<prefix> Shift+Tab` — вернуться к предыдущей сессии

## Окна

- `<prefix> c` — создать новое окно
- `<prefix> Ctrl+H` — перейти к предыдущему окну
- `<prefix> Ctrl+L` — перейти к следующему окну
- `<prefix> Tab` — перейти к последнему активному окну
- `<prefix> e` — открыть `tmux.conf.local` в редакторе и затем перечитать конфиг
- `<prefix> r` — перечитать конфиг `tmux`

## Панели

- `<prefix> -` — разделить окно горизонтально, то есть создать панель снизу
- `<prefix> \` — разделить окно вертикально, то есть создать панель справа
- `<prefix> h` — перейти в панель слева
- `<prefix> j` — перейти в панель снизу
- `<prefix> k` — перейти в панель сверху
- `<prefix> l` — перейти в панель справа
- `<prefix> H` — сузить текущую панель влево
- `<prefix> J` — увеличить текущую панель вниз
- `<prefix> K` — увеличить текущую панель вверх
- `<prefix> L` — увеличить текущую панель вправо
- `<prefix> <` — поменять текущую панель с предыдущей
- `<prefix> >` — поменять текущую панель со следующей
- `<prefix> +` — развернуть или свернуть текущую панель
- `<prefix> q` — показать номера панелей
- `<prefix> m` — включить или выключить мышь
- `<prefix> F` — запустить `pathpicker` для текущей панели

## Режим копирования

В конфигурации включён `vi`-режим:

- `<prefix> Enter` — войти в `copy-mode`
- `<prefix> [` — войти в `copy-mode`

Внутри `copy-mode-vi`:

- `v` — начать выделение
- `Ctrl+V` — включить прямоугольное выделение
- `y` — скопировать выделение и выйти
- `Escape` — выйти из режима копирования
- `H` — перейти в начало строки
- `L` — перейти в конец строки

## Буферы

- `<prefix> b` — показать список буферов
- `<prefix> p` — вставить верхний буфер
- `<prefix> P` — выбрать буфер для вставки

## Что переопределено относительно стандартного поведения

- `Ctrl+A` добавлен как второй префикс, но `Ctrl+B` остаётся рабочим
- `n` и `p` как переключение окон отключены
- вместо них используются `<prefix> Ctrl+H` и `<prefix> Ctrl+L`
- `Ctrl+L` без префикса очищает экран и историю, а с префиксом переключает на следующее окно
- в `copy-mode` добавлен вход по `<prefix> [`

## Важная деталь по `copy-mode`

В `tmux.conf.local` есть две последовательные привязки для клавиши `y` в `copy-mode-vi`. Последняя привязка побеждает, поэтому фактически активное поведение такое:

- `y` делает `copy-selection-and-cancel`

То есть копирование в системный буфер через `xclip`, записанное строкой выше, этой же локальной конфигурацией затем перекрывается.
